# First Telegram testers

Target: invite 5–10 developers who already run long agent tasks; at least three complete setup independently and use it again. These are validation targets, not achieved results or forecasts. No independent testers have been recruited in this run.

## Invitation draft

Your coding agent is waiting for a decision. Reply from Telegram and keep the task moving.

I’m testing DoneRelay, an open-source, self-hosted bridge for Telegram notifications, questions, and bounded approvals. It needs Node.js 22+, your bot, and a still-running integrated agent workflow. This is an early alpha with the remaining limits recorded publicly.

Would you try one harmless task, receive one message, answer one question, and tell me where you got stuck? Setup: https://tianxinzh.github.io/DoneRelay/ . Please do not send tokens or private task contents in feedback.

## Tester checklist

1. Follow the README without live help from the author. Record time to first message and any unclear step.
2. Run `doctor` with your private agent configuration. If it fails, share only check names and redacted guidance.
3. Receive a completion notification, answer a harmless question, approve one disposable operation, and deny another. Do not begin with production actions.
4. Record Node, OS, DoneRelay commit/release, and agent version. State which checks used a real phone and which used fixtures.
5. Try it on a second occasion. Report what made you return, or why you stopped.

Use the repository issue template for redacted setup problems. Keep contact details and recruitment tracking private. Track invited, started setup, completed independently, time to first message, repeat usage, reported issues, and voluntarily observed stars. Do not count the author's own tests as independent setups.

## Outreach gate

The owner needs to provide the intended 5–10 contacts or select communities and posting accounts. No invitations or community posts have been sent. Check each community's current project-post rules before sharing; do not send unsolicited mass outreach.
