# Discoverability and launch

## Positioning

**DoneRelay — Telegram approvals and questions for AI agents.**

Use the brand consistently. Useful search phrases are “Codex Telegram notifications”, “Claude Code Telegram approval”, “AI agent human-in-the-loop”, and “WeChat agent notifications”. Place them where they describe real behavior, not in repeated keyword blocks. Do not claim a unique trademark or absence of competitors without separate diligence.

Suggested GitHub About text (metadata still needs owner/settings access):

> Telegram notifications, questions & single-operation approvals for Codex, Claude Code and AI agents. Experimental personal WeChat support. Self-hosted Node.js + Agent Skill.

Suggested topics:

`agent-skills`, `codex`, `claude-code`, `telegram-bot`, `wechat`, `weixin`, `human-in-the-loop`, `ai-agents`, `notifications`, `self-hosted`, `nodejs`.

## Convert a visitor into a successful user

Keep the README's one-sentence use case, no-credential demo, status table and copyable install command above lengthy architecture material. The first real demo should show a task waiting, the phone approval, then the same task continuing; redact tokens and private content. Clearly distinguish simulated output from a live capture. The primary outcome is successful setup and repeated useful use, not raw stars.

## Make the project easy to cite accurately

Maintain stable documentation paths, a versioned changelog, a plain-language FAQ, explicit support boundaries, and links to primary upstream specifications. Keep the skill description consistent with actual tool behavior. `llms.txt` is a navigation aid, not a guaranteed ranking signal. Avoid fabricated benchmarks, testimonials, installs, or “official partner” language. SEO/GEO outcomes and star growth are not guaranteed by this work.

## Launch sequence

First recruit a small number of real testers with long-running coding jobs. Resolve installation friction. Publish a short real demo and a focused technical explanation of expiring approvals and sender binding. Submit to relevant directories using their actual publisher flow. Share once in communities that permit self-promotion, disclose authorship, and lead with the problem solved. Link all announcements back to the canonical repository.

Suggested post:

> I built DoneRelay because long-running coding agents often need a decision just after I leave the keyboard. It lets a configured agent ask on Telegram, wait for a scoped answer or approval, then continue. The core is self-hosted Node.js; the personal WeChat adapter is experimental. I am looking for installation feedback and live-channel testers, not a claim that it already works with every host.
