# Changelog

## 0.1.0 — initial implementation (2026-09-12)

- Node.js HTTP bridge and portable CLI with SQLite state, idempotency and expiring single-operation decisions.
- Telegram private-chat notifications, reply questions and approval buttons with long polling.
- Experimental personal WeChat outgoing worker and deterministic OpenClaw reply plugin.
- Narrow experimental Codex App Server command-approval callback helper; no automatic native Claude hook.
- Portable Skill and OpenAI/Claude repository marketplace manifests; English/Chinese docs, security and submission checklist.
- Offline tests and demo. Live channel, host-native integration, Docker execution and reviewed marketplace listing remain release gates.
